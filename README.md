# Ridge Customizer Prototype

Clickable prototype for a Ridge product-page personalization drawer.

## What It Shows

- Left-side personalization drawer that keeps the product page visible.
- Guided flow: Kit, Finish, Color, Design, Placement, Review.
- Dependent color and design options based on personalization method.
- Review step before adding the personalized product to cart.
- Bulk-order link treatment for larger orders.

## Run Locally

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173/`.
